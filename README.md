# IT-Inventory 1C (Учёт и инвентаризация IT-оборудования)

Пет-проект по разработке конфигурации на платформе **«1С:Предприятие 8.3»** (управляемые формы).  
Проект ведется разработчиком с бэкграундом в **C++** для практического освоения архитектуры 1С, метаданных, транзакционной модели и механизмов интеграции.

---

## 🎯 Назначение конфигурации

Учёт парка компьютерной техники компании, выдачи оборудования сотрудникам и движения комплектующих.

---

## 🏗 Архитектура решения (Текущее состояние)

### Справочники (Master Data)
- **`Сотрудники`** — учёт персонала (`ФИО`, `Должность`, `Email`).
- **`Оборудование`** — единицы техники (`Модель`, `ТипОборудования`, `СерийныйНомер`, `ИнвентарныйНомер`).

### Перечисления (Enums)
- **`ТипыОборудования`** (`Ноутбук`, `Монитор`, `СистемныйБлок`, `Периферия`).

### Документы (Transactions / Events)
- **`ВыдачаОборудования`** — регистрация передачи техники сотруднику:
  - Шапка: `Сотрудник`, `Комментарий`, стандартные реквизиты (`Номер`, `Дата`).
  - Табличная часть `СписокОборудования`: связь one-to-many со справочником `Оборудование` + поле `Примечание`.

---

## 🗺 Дорожная карта развития (Roadmap)

- [x] **Этап 1:** Базовые метаданные (Справочники, Перечисления, Документы с табличными частями).
- [ ] **Этап 2:** Клиент-серверная логика (`&НаКлиенте` / `&НаСервере`), валидация заполнения, автоматические события форм.
- [ ] **Этап 3:** Печатные формы (Макет «Акт приёма-передачи техники» в табличный документ).
- [ ] **Этап 4:** Регистры накопления и сведений (контроль состояния техники: на складе / выдана / в ремонте).
- [ ] **Этап 5:** Отчёты на СКД (Система компоновки данных) — ведомость закрепления техники за сотрудниками.
- [ ] **Этап 6:** Интеграция по HTTP / REST API (приём заявок на выдачу техники из внешней системы).
