# IT-Inventory 1C (Учёт и инвентаризация IT-оборудования)

Пет-проект по разработке конфигурации на платформе **«1С:Предприятие 8.3»** (управляемое приложение).  
Проект ведется разработчиком с бэкграундом в **C++** для практического освоения архитектуры платформы 1С, метаданных, транзакционной модели проведения и аналитики СКД.

---

## 🎯 Назначение конфигурации

Учёт парка компьютерной техники компании, выдачи оборудования сотрудникам, контроль текущего состояния девайсов и аналитика закрепления техники.

---

## 🏗 Архитектура решения

### Справочники (Master Data)
- **`Сотрудники`** — учёт персонала (`ФИО`, `Должность`, `Email`).
- **`Оборудование`** — единицы техники (`Модель`, `ТипОборудования`, `СерийныйНомер`, `ИнвентарныйНомер`).
  - *Оптимизация:* включена СУБД-индексация полей `СерийныйНомер` и `ИнвентарныйНомер` и настроен быстрый поиск (`Ввод по строке`).

### Перечисления (Enums)
- **`ТипыОборудования`** (`Ноутбук`, `Монитор`, `СистемныйБлок`, `Периферия`).
- **`СостоянияОборудования`** (`ВЭксплуатации`, `НаСкладе`, `ВРемонте`, `Списано`).

### Документы (Transactions / Events)
- **`ВыдачаОборудования`** — регистрация передачи техники сотруднику:
  - Шапка: `Сотрудник`, `Комментарий`, системные реквизиты (`Номер`, `Дата`).
  - Табличная часть `СписокОборудования`: связь 1:N со справочником `Оборудование` + поле `Примечание`.
  - Модуль объекта: перехват события `ОбработкаПроверкиЗаполнения` (валидация обязательных полей с подсветкой в UI через `СообщениеПользователю`, контроль дубликатов в табличной части через группировку `Свернуть()`).
  - Автозаполнение: точное время создания документа через `ОбработкаЗаполнения`.

### Регистры (State & Time Series)
- **Регистр сведений `СостояниеОборудования`** (Периодический, режим записи: *Подчинение регистратору*):
  - Измерения (PK): `Оборудование`.
  - Ресурсы: `Сотрудник`, `Состояние`.
  - Регистратор: `ВыдачаОборудования`.
  - Логика проведения: в процедуре `ОбработкаПроведения` документ формирует движения по регистру. При отмене проведения или удалении документа платформа автоматически откатывает движения (ACID).

### Печатные формы (Templates & Reporting)
- **«Акт приёма-передачи техники»**: макет на базе табличного документа (`ТабличныйДокумент`), формируемый процедурой печати в модуле менеджера на основе выборки из документа. Вывод на печать и экспорт в PDF/Excel.

### Аналитическая отчетность (СКД / OLAP)
- **Отчет «Закрепленное оборудование»**:
  - Построен на **Системе компоновки данных (СКД)**.
  - Источник данных: виртуальная таблица `РегистрСведений.СостояниеОборудования.СрезПоследних`.
  - Иерархическая группировка: `Сотрудник` ➔ Детальные записи (`Оборудование`, `ТипОборудования`, `СерийныйНомер`, `Состояние`).
  - Агрегатные итоги: автоматический расчет ресурса `Количество(Оборудование)` по каждому сотруднику и общий итог.

- [x] **Этап 1:** Базовые метаданные (Справочники, Перечисления, Документы с табличными частями).
